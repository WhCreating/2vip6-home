О проекте

TUI Console — это концепт веб-сайта, вдохновлённый терминальными интерфейсами.

Он использует только текстовые символы, монотипные шрифты и цветовую палитру, характерную для консольных приложений.

Версия: 2vip6
Технологии: HTML / CSS / JS
Лицензия: MIT
[ УСТАНОВИТЬ ]

Установить 2vip6

Скопируйте и выполните команду ниже в вашем терминале.

● ● ● bash — 2vip6
$ curl -fsSL https://2vip6.dev/install.sh | bash
$ 2vip6 init --theme tui
